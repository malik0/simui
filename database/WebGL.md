# WebGL

A JavaScript API for GPU-accelerated 2D and 3D graphics in the browser, based on OpenGL ES.

- Programs run on the GPU as [[Shaders]] written in GLSL.
- WebGL 2 is based on OpenGL ES 3.0 and is widely supported.
- Low level and verbose, so most projects use [[Three.js]].
- Is the rendering backend for [[WebXR]] sessions.
- WebGPU is the newer successor API.
